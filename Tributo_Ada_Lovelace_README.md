# Tributo a Ada Lovelace

Este projeto é um site simples em **HTML5** e **CSS3** criado como um tributo a **Ada Lovelace**, a primeira programadora da história. Ele destaca sua vida, contribuições e legado no campo da ciência da computação.

## Funcionalidades
- **Design Responsivo:** Adapta-se a vários tamanhos de tela para uma visualização ideal em diferentes dispositivos.
- **Layout Limpo:** Foco na legibilidade e estética com um design moderno e minimalista.
- **Conteúdo Informativo:** Inclui detalhes sobre a vida, contribuições e impacto de Ada Lovelace na tecnologia.

## Tecnologias Utilizadas
- **HTML5:** Para a estrutura do site.
- **CSS3:** Para estilização e layout.

## Como Usar
1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Explore o conteúdo para saber mais sobre Ada Lovelace.

## Estrutura de Arquivos
```
├── index.html      # Arquivo HTML principal
├── README.md       # Documentação do projeto
└── assets/         # Diretório para imagens (se adicionadas no futuro)
```

## Demonstração ao Vivo
Para visualizar o site, basta abrir o arquivo `index.html` no seu navegador ou hospedá-lo em uma plataforma como o **GitHub Pages**.
